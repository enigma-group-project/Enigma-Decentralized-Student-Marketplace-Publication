Three Solidity 0.8.20 contracts on the **audited** OpenZeppelin v5.1.0 libraries — `EnigCredit` (ERC-20), `Marketplace` (listings+escrow), `Reputation` — with an ethers.js front end targeting Anvil (31337) or Sepolia (11155111).

**Security by standards:** every primitive reuses an audited OpenZeppelin module (`ERC20`, `ERC20Permit`/EIP-2612, `Ownable`, `ReentrancyGuard`, `SafeERC20`, `Pausable`), shrinking the custom attack surface. Threats & mitigations: unauthorized mint → `Ownable` owner-only (a capped, rate-limited public faucet supplies demo top-ups only); payment theft/reentrancy → escrow + checks-effects-interactions + `ReentrancyGuard` + `SafeERC20`; reputation forgery/double-rating → one-time rating bound to the buyer of a completed sale; seller non-delivery → timeout refund. Solidity 0.8.20 checked arithmetic + custom errors; verified in CI by unit/fuzz/invariant tests + Slither static analysis.
