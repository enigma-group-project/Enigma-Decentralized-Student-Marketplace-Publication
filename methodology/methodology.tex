All measurements use the Foundry toolchain~\cite{foundry}. Functional correctness is established with \texttt{forge test} over per-slice suites (\texttt{EnigCreditTest}, \texttt{ListingsTest}, \texttt{EscrowTest}, \texttt{ReputationTest}); adversarial robustness adds property-based fuzzing and stateful invariant tests (\texttt{Invariant.t.sol}). Gas is collected with \texttt{forge test --gas-report} (average per call). Static analysis runs Slither~\cite{feist2019slither} as a required continuous-integration job on every pull request. The contracts are deployed both to a local Anvil chain (chainId~31337) and to the public Sepolia testnet (chainId~11{,}155{,}111), and exercised end-to-end through a dual-network ethers.js web client. The entire pipeline---build, test, and static analysis---re-runs automatically in CI, making every reported result reproducible from a clean checkout.
